    Через что работает ассистент
    Адрес OpenAI-совместимого API: студия обращается к {Base URL}/chat/completions и {Base URL}/models. Модель должна поддерживать вызов функций (tools).
    1. Установите Claude Code и войдите: claude login. Нужен Node.js 18+.
    2. Скачайте локальный сервер — он уже настроен на эту студию и ваш личный токен.
    3. Распакуйте и запустите: node server.js (или start.cmd / start.sh).
    4. Нажмите «Проверить соединение».
    Токен:
    . Ключ хранится только в этом браузере и отправляется напрямую провайдеру, не на сервер студии.
    Дополнительно
    Обычно не нужно. Логин и пароль хранятся только в этом браузере и отправляются только этому сервису.
